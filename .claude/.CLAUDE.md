# Frontend

Components:    PascalCase filename == exported component name
Pages:         PascalCase filename, matching PascalCase default export
Hooks:         use-<resource>.js, react-query for all server state, { data, isLoading, error }
Imports:       @/ alias for cross-folder imports; relative only within the same folder

# Colors

All colors come from the semantic tokens in client/src/index.css (CSS variables) and
client/tailwind.config.js (Tailwind classes). Never hardcode hex/rgb in a .css file or as an
inline style or arbitrary Tailwind value (bg-[#...]) — if a needed shade doesn't exist as a
token, add it to index.css/tailwind.config.js first.

Token      Hex        Tailwind classes                  Use
primary    #166534    bg-primary / text-primary / ...   brand actions: buttons, links, focus rings, active nav/pagination
secondary  #f1f9f5    bg-secondary                       subtle brand-tinted surfaces
accent     #fbbf24    bg-accent / text-accent            highlights, promo badges, callouts (accent-foreground is dark, not white)
success    #0f5132    bg-success / text-success          positive status only: active/enabled records, in-stock, delivered
warning    #d97706    bg-warning / text-warning           caution status: low stock, pending (warning-foreground is dark, not white)
destructive #ef4343   bg-destructive                      errors, delete, inactive/negative status
neutral    #676f7e    text-muted-foreground               secondary/muted text
border     #e5e7eb    border-border / border-input
background #f0f2f4    bg-background

Blue (text-blue-*, bg-blue-*) is intentionally NOT part of this system — it's used as a
distinct "info/in-progress" status color (e.g. order status "shipped", promotion type
"POPULAR") separate from success/warning/destructive. Same for orange/purple category tags
(e.g. promotion type HOT/DISCOUNT) — those are deliberate multi-hue category systems, not
brand colors, and should stay as literal Tailwind utilities.

Dark mode values live in the `.dark { ... }` block in index.css (same token names, no code
changes needed elsewhere — just toggle the `dark` class on `<html>`).
